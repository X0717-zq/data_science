# 第七章结果入口

正文：`第七章_模型解释与业务应用.md`。五张图均提供PNG/PDF/SVG；其插入位置见`图表插入位置与使用说明.md`。图7-4位于表7-2之后，图7-5位于7.2.2文字之后；表7-3、表7-4分别位于7.2.3与7.2.4。

本次完成五轮冻结RF-Plain复现、7,460次测试预测精确TreeSHAP、1,200次原始字段置换；原数据、原九组结果和神经网络实验未更改。

参数与代码继续分离，均保存在本文件夹上两级的实验包根目录：
- `chapter7_explainability_config.json`：模型、置换次数、解释配置、案例、图形参数。
- `run_chapter7_explainability.py`：核验并计算解释；修改模型参数后若无法匹配冻结结果将停止，不会冒充原模型解释。
- `plot_chapter7_explainability.py`：用保存的结果绘图。
- `chapter7_risk_groups_config.json`、`plot_chapter7_risk_groups.py`：图7-4/7-5的分组与绘图配置、代码；读取表7-2同源数据并按交易编号去重复核。
- `build_chapter7_report.py`：构建报告与引用表。

主要核验：五轮分数差为0；SHAP重构误差约1e-15；商户类别有符号贡献合并保持加性；源文件哈希保持不变。数值核验见`qa/numerical_verification.json`，完整交付核验见`qa/delivery_verification.json`。

说明：SHAP解释本次模型分数，不能解释为因果；测试置换是事后诊断，不用于本次特征筛选和阈值调整；五轮SD不是置信区间。实验数据并不能证明生产环境适用性。

图7-4/7-5是五轮测试并集5,485笔不同交易的描述性比例，不是五轮均值，未添加推断性误差线。每个面板覆盖全部去重交易，跨面板计数不能相加。
